# 🎬 Netflix Case Study – Data Analysis with Python

This project provides an exploratory data analysis of Netflix’s content catalog using Python. The goal is to extract insights related to genres, content type, duration, and release trends by leveraging powerful Python libraries like Pandas, NumPy, Matplotlib, and Seaborn.

---

## 📁 Project Structure

- `netflix_case_study.ipynb` – Jupyter Notebook containing the complete analysis, visualizations, and insights
- `README.md` – Project documentation

---

## 🧰 Tools & Libraries Used

- Python 3
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 🔍 Key Questions & Analysis

1. **Top Genres**  
   Identified the 5 most frequently occurring genres in the dataset to understand Netflix’s primary content focus.

2. **Duration Analysis**  
   Analyzed values in the `duration` column to see how long content typically runs and how it's distributed across types.

3. **Content Categorization**  
   Filtered and displayed entries based on content type: TV Shows and Movies. Two entries from each category were showcased.

4. **Oldest Movie**  
   Determined the oldest movie available on the platform by identifying the minimum release year.

5. **Duration Statistics**  
   Extracted numeric values from the `duration` column and calculated:
   - Mean
   - Median
   - Mode
   - Standard Deviation  
   These measures help understand the spread and central tendency of content lengths.

6. **Release Year Distribution**  
   Created a histogram to visualize the distribution of content release years to identify patterns in production over time.

---

## 📊 Insights Summary

- Netflix features a wide range of genres, with **Drama** and **International Movies** being among the most common.
- The platform's content is heavily skewed toward **movies**, but **TV Shows** have a significant presence as well.
- Duration analysis revealed that a majority of content falls within typical movie lengths, with a few outliers.
- The **oldest movie** in the dataset dates back to early 1900s, showcasing Netflix’s inclusion of classic titles.
- Central tendency and spread values for duration provide an understanding of content length expectations.
- The histogram of release years shows Netflix has added a majority of its content post-2000s, aligning with streaming trends.
